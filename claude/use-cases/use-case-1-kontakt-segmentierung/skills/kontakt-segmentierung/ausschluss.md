# Ausschlussliste

Firmen auf dieser Liste lässt Claude beim Einlesen weg, etwa weil sie schon Kunden der Agentur sind, gerade in einem Angebot stecken oder du sie selbst ansprichst. Je Firma eine Zeile mit Bindestrich davor, so wie im Export geschrieben. Rechtsformen wie GmbH, AG oder SE und Groß- und Kleinschreibung spielen keine Rolle.

Liegt im Ordner `kontakte/` deines Arbeitsordners eine eigene `ausschluss.md`, gilt diese statt dieser Datei. So hat jeder Anlass seine eigene Liste.

Die Liste ist anfangs leer. Sag Claude zum Beispiel „nimm die Musterbank in die Ausschlussliste auf".
