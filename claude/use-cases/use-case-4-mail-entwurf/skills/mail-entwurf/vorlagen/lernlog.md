# Lernlog Mail-Stil

Jede bestätigte Korrektur an einem Entwurf, als Vorher, Nachher und Regel. Die Regeln gelten bei jedem neuen Entwurf wie die Kernregeln. Ab rund zehn Einträgen schlägt Claude vor, die gesicherten Regeln ins Profil oder in das Register zu übernehmen und das Log zu kürzen.

Eintrag (Muster):

```
## <Datum> | Register <slug> | <Empfängertyp>
- Vorher (Claude): „...“
- Nachher (ich): „...“
- Regel: <ein Satz im Imperativ>
```
